Attendees run their own side events all weekend: races, side tournaments, card
games, board game nights, meetups and more. They aren't part of the official
schedule and we don't run them, but we give them a home in the app so you can
find them.

## Finding them

Open Event on Home and switch to **Community**. Everything that hasn't finished
yet is there, grouped by day, with the time, where it is and who's hosting. When
new events go up, the Event tab shows how many.

A lot of them happen in the casual room (Corcoran / Veritas / Chrysalis, lower
level) or the board game room (Tarara, basement). Hosts also post about them in
the community events and board game room channels on the
[event Discord](https://discord.com/invite/T6qzxNJ).

## Joining in

Each event has one button, depending on what the host picked.

| You see | What it does |
|---|---|
| **Remind me** | We DM you on Discord 30 minutes before it starts. |
| **RSVP** | Tells the host you're coming and gets you the same reminder. |
| **Full** | Every place is taken. If someone drops out, the button comes back. |

Changed your mind? Tap **Subscribed** or **Going** to back out. If the host moves
the event or calls it off, you'll get a DM.

Events you're hosting, going to or have a reminder for also show up on
My Schedule under Timeline, right alongside your matches.

## Running your own

Tap **Submit an event** at the top of the Community list. Give it a title, a
start time and a length, and say where it is so people can find you. Turn on
**Take RSVPs** if you want a headcount, and set a cap if space is tight.

Staff look over each event before it's listed. You'll get a DM once it's
approved, or the reason if it isn't.

Rather not post it yourself? Ask staff. They can put it up with you as the
host, and you'll get a DM saying so.

To change or call off your event, open its page and use **Edit** or
**Cancel event…** in the ⋮ menu. Everyone who's going or asked for a reminder
hears about it. A cancelled event can't come back, so post a new one if plans
change again.

The [Community events help page](/help/community-events) has the rest.
