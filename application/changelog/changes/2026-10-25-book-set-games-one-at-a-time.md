### Improved

- Players book a best-of-three's games one at a time, and in any order: "Waiting on you to pick a time" shows a row for each game left, with the deciding game marked "If needed". Schedules number the games by when they're played, so moving game 3 ahead of game 2 swaps their numbers.
- Calling off one game of a best-of-three no longer takes the rest of the set with it.
