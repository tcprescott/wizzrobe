### New

- Tournaments can run as group races: the bot opens a room anyone can join before each race, posts it in your Discord channel with an optional role ping, posts the seed and can lock the room. Set it up on a tournament's Racetime tab in the app.
- Qualifier live races with a start time now open their own racetime room, post it in Discord and post the seed on time. Set it up on the qualifier's Settings page in the app.
