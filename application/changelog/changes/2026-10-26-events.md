### New

- A community can now run several events. Staff create, copy, take live, archive and set the default one under Admin → Events, and the event button beside the community name switches between them.
- Each event has its own dates, hours, capacity, venue, timezone and volunteer reward tiers under Admin → Event settings.
- My Schedule, My Shifts and Home › Tournaments show every live event you're in, with the event's name on a row once two events share the list, and links back to past events.

### Improved

- The Admin menu is split in two: what belongs to the event you're looking at, then what's the same across the community.
- Community Events are now called Meetups.
