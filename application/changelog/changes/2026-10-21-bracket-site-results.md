### Fixed

- Confirming a match no longer overwrites a result an admin already entered on Challonge. Wizzrobe checks first and leaves Challonge's result alone, as it already did for start.gg.
- Reconnect on Settings → Integrations takes you straight to Challonge's (or start.gg's) sign-in. Before, the first press only reloaded the page and you had to press it again.

### Improved

- The Challonge card shows this month's API request count without the old 500 cap, which didn't match the plan we're on.

### New

- Staff can have Wizzrobe sync Challonge brackets automatically, anywhere from every 15 minutes to every 6 hours, under Settings → Integrations → Challonge. The card shows roughly how many API requests a day that costs.
- A booked match someone already reported on Challonge or start.gg now shows "Played on Challonge" (or start.gg) on Match Schedule and appears under Needs you. Record result copies the site's winner and confirms the match without sending check-in or start DMs. Call off cancels it.
