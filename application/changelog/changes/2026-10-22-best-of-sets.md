### New

- Best-of-3 (and 5) sets on Challonge and start.gg brackets are now booked as one match per game, each with its own time, seed, stage and crew. Set which rounds play best of 3 under Admin → Tournaments ⋮ → Round schedule, or change it for one matchup when you book it. The booking dialog fills the games in back to back and marks the last one "If needed".
- Once someone wins the set, Wizzrobe sends the result to the bracket with the game score (2–0 or 2–1) and calls off any game nobody needs, crew included. Before this, confirming game 1 would have reported the whole set.
