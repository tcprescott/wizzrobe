### Improved

- On-site roles (Proctor, Broadcast Tech, Triforce Submitter, Volunteer Coordinator, Equipment Manager, Volunteer and Check-in Desk) are now held in one event, so a proctor for this year's event isn't automatically one for next year's. Staff, Preset Manager, Sync Admin and Qualifier Admin still cover every event. Existing grants moved to each community's default event.
- Edit member shows community-wide roles and roles in one event (pick the event beside the label), with a line naming what the person holds in other events. The Members list names the event for roles held elsewhere.
- Discord role mappings for on-site roles name the event they grant in, the default event unless you pick another.
